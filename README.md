## Prebuilt Wiring

| Application                                               | Description                                       |
| --------------------------------------------------------- | ------------------------------------------------- |
| [`cloudflare_r2`](https://developers.cloudflare.com/r2/)  | S3 storage buckets for dataset bytes and blobs    |
| [`coderabbit`](https://docs.coderabbit.ai/)               | Automated pull request review                     |
| [`docker_desktop`](https://docs.docker.com/desktop/)      | Container instance for running apps locallly      |
| [`fastapi`](https://fastapi.tiangolo.com/)                | Python API for backends deployed to Render        |
| [`hugging_face`](https://huggingface.co/docs)             | Model and dataset storage, hosting, and inference |
| [`mlflow`](https://mlflow.org/docs/latest/)               | Machine learning pipeline observability           |
| [`modal`](https://modal.com/docs)                         | Serverless compute for machine learning jobs      |
| [`playwright`](https://playwright.dev/docs/intro)         | Portal smoke tests in CI                          |
| [`pnpm`](https://pnpm.io/)                                | Package manager for the TypeScript monorepo       |
| [`posthog`](https://posthog.com/docs)                     | Frontend product analytics and session replays    |
| [`prisma`](https://www.prisma.io/docs)                    | Database ORM for TypeScript heavy monorepo        |
| [`pytest`](https://docs.pytest.org/)                      | Python unit tests for the shared package          |
| [`react`](https://react.dev/)                             | UI library for the Next.js frontends              |
| [`redis`](https://redis.io/docs/latest/)                  | Background job queue for Python RQ workers        |
| [`render`](https://render.com/docs)                       | Deployment platform for FastAPI and Node services |
| [`sentry`](https://docs.sentry.io/)                       | Backend exception tracking and observability      |
| [`sql_alchemy`](https://docs.sqlalchemy.org/en/21/)       | Database ORM for Python heavy monorepo            |
| [`supabase_postgres`](https://supabase.com/docs)          | Database postgres instance for tables             |
| [`supabase_s3`](https://supabase.com/docs/guides/storage) | S3 storage buckets for model artifacts or bytes   |
| [`vercel`](https://vercel.com/docs)                       | Deployment platform for Next.js frontends         |
